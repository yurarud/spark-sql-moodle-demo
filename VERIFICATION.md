# Виконані перевірки

Перевірено 29 жовтня 2026 року в Linux, Python 3.12, Java 17 та PySpark 3.5.7, у локальному режимі `local[2]`.

## Результат

- Пройдено 6 інтеграційних тестів із `tests/test_demo.py`.
- Повний малий запуск завершився успішно. Аудит: 10 вхідних рядків, 2 відхилені, 1 повтор серед прийнятних, 7 очищених.
- Автоматично підтверджено еталони денних показників, рейтингу та віконного тренду.
- Підтверджено еквівалентність SQL і DataFrame та кількість рядків після запису й читання Parquet.
- Виконано великий режим із 10 000 базових записів, 4 партиціями та `hot-percent=80`.
- Після додавання повторів отримано 10 010 вхідних рядків, 148 відхилених, 9 повторів серед прийнятних і 9 853 очищені події.
- Виконано benchmark JOIN: по одному прогріву та по 2 вимірювані записи для кожної стратегії, зі зміною порядку.
- Двостороння перевірка результатів JOIN пройшла. У збережених планах знайдено `SortMergeJoin` та `BroadcastHashJoin`.
- У плані читання Parquet підтверджено наявність `PartitionFilters`.

Час конкретного запуску залежить від середовища. Наведені перевірки підтверджують роботу прикладу; вони не доводять універсального прискорення broadcast і не замінюють вимірювань на кластері.

YARN і GitHub Actions у цьому середовищі не запускалися. Інструкція YARN розрахована на `client` mode та наявну конфігурацію навчального кластера. Робота сценарію GitHub Actions перевірятиметься після публікації репозиторію.
