# Чеклист демонстрації

## До заняття

- Перевірити Java 17, Python та встановлення `requirements.txt`.
- Виконати `python -m unittest discover -s tests -v`.
- Зарезервувати нові каталоги виходу й звіту для показу.
- Відкрити CSV, очікувані результати та файл `src/moodle_demo.py`.

## Під час малого запуску

- Аудит: 10 рядків, 2 неприйнятних, 1 повтор серед прийнятних, 7 очищених.
- Денні показники: 4 рядки, загалом 7 подій.
- Рейтинг: по 2 користувачі в кожному курсі.
- SQL/DataFrame: двостороння різниця порожня.
- Parquet: число очищених подій після читання збігається.
- Spark UI працює до Enter, якщо вказано `--pause`.

## Під час великого запуску

- Порівняти `--hot-percent 0` і `--hot-percent 95` на однакових базових обсягах.
- Дослідити Tasks та Exchange, врахувати часткове агрегування і AQE.
- Для JOIN використати `--benchmark`, перевірити фактичні плани й медіани.
- Не оголошувати прискорення за одним запуском або лише за назвою оператора.
